Sprint v6.14: Production Hardening, Telemetry Edge-Sync & Session Resilience

This commit completes the tasks required for Sprint v6.14:
- Auth & Dashboard Session Shielding: ProtectedRoute gracefully handles transient network drops without logging the user out. Dashboard tabs maintain their state during sub-tab switches using CSS `display` logic instead of unmounting.
- Telemetry Pipeline & Edge Worker Activation: useTelemetry.js batches telemetry events and correctly implements `navigator.sendBeacon` for edge syncing on page unload.
- Cloudflare Edge Caching & Service Worker Synchronization: public/_headers correctly caches assets. Service worker updates trigger a seamless reload by dispatching `SKIP_WAITING` via `UpdatePrompt.jsx`.
- UI/UX Refinement & Enterprise Micro-Interactions: AutomationCalculator includes a 'Copy Summary' action. TelemetryStatus uses lighter text for improved contrast. SearchOverlay is visually accessible and properly handles keyboard commands.
