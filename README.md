## Cloudflare Pages deployment

Deploy the `dist` directory generated by `npm run build`. The build creates
`dist/200.html` as the Cloudflare Pages SPA fallback, so client-side deep links
continue to return the application shell without an invalid `_redirects` rewrite.
Cloudflare Pages Functions are deployed from `functions/`.
